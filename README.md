# 🚀 My Portfolio Website

Welcome! This is my portfolio website, built completely from scratch using **HTML**, **CSS**, and **JavaScript**. 

## 🟢 Live Site 🌐 
*Coming soon via Vercel!*

## 🤔 Why this project?

This project sparked from a curiosity about what actually happens after UX designers hand off their ideas to developers. I believe this hands-on dive into the dev process will help me become a better collaborator at all touchpoints from ideation to shipment. 

Along the way, I hope to learn: 
* Git and GitHub
* Vibecoding and prompt engineering
* AI-intergration into design workflows 
* Markdown

## 🛠️ Built With
* Pure HTML5 for structure
* Custom CSS3 for styling
* GitHub Copilot as my AI coding assistant
* Google Gemini as my SME
* Deployed on Vercel
